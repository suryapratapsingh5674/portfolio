## Overview

This repository houses the personal portfolio of **Surya Tomar**, a Full-Stack Developer specializing in building high-performance web applications, scalable backend systems, and AI-integrated digital products. 

Designed with a sleek, dark-mode aesthetic and glassmorphism accents, the site merges visual sophistication with clean engineering principles.

---

## Key Highlights & Experience

### 🌌 Interactive 3D Hero Scene
- **Three.js & React Three Fiber integration** with procedural particle mesh and interactive geometric nodes.
- **Dynamic camera & cursor parallax** responsive to user movement.
- **Progressive lazy-loading architecture** with lightweight SVG fallback ensuring instant First Contentful Paint (FCP).

### 🎯 Modern Visual System & Micro-Interactions
- **Custom Cursor System**: Dual-ring trailing pointer with dynamic expansion over interactive elements.
- **Scroll Progress & Spatial Awareness**: Real-time reading progress bar paired with staggered viewport reveal animations.
- **Ambient Lighting**: Multi-layered background grid and radial gradient glow elements that adapt across screen sizes.
- **Radial Highlight Cards**: Mouse-tracking spotlight effects that illuminate project cards upon hover.

### 💼 Featured Works & Case Studies
- **Resumind**: AI-powered resume parsing and scoring system powered by Google Gemini API.
- **Foodly**: Full-stack multi-role food discovery and menu management platform with JWT authentication and ImageKit media storage.
- **DevEvents**: SEO-first event discovery hub designed with server-side rendering and structured metadata.
- **Movie Info App & URL Shortener**: Real-time API integrations, analytics tracking, and responsive dashboard interfaces.
